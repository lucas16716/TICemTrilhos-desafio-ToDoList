## PROJETO

O **Do It List** é uma aplicação web de gerenciamento de tarefas, desenvolvida com uma identidade visual original inspirada no conceito **"Just Do It"**.

O projeto nasceu de uma ideia própria e foi construído do zero, passando pela criação do conceito visual, desenvolvimento da marca e implementação da interface e das funcionalidades.

A proposta é oferecer uma experiência simples, objetiva e responsiva para adicionar, organizar, concluir e remover tarefas.

🌐 [Acesse o site](https://do-it-list.vercel.app/)&nbsp;&nbsp;|&nbsp;&nbsp;📹 [Vídeo do projeto](https://www.instagram.com/p/DFlsQsCxGhY/)

## FUNCIONALIDADES

- **Gerenciamento de tarefas** — adicionar, marcar como concluída e remover tarefas
- **Temas personalizáveis** — alternância entre modo claro (amarelo) e escuro (azul)
- **Identidade visual própria** — interface inspirada no conceito "Just Do It"
- **Barra de rolagem personalizada** — experiência visual alinhada à interface
- **Layout responsivo** — adaptação para diferentes dispositivos

## APRENDIZADOS

Durante o desenvolvimento, o projeto contribuiu para a prática de:

- Criação de uma aplicação web com operações básicas de CRUD
- Manipulação do DOM com JavaScript
- Implementação de troca de temas utilizando variáveis CSS
- Estruturação de uma interface responsiva
- Desenvolvimento de uma identidade visual para um produto digital
